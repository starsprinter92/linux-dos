# DOS-Linux

a DOS-inspired command-line shell for Linux. fully vibecoded. use at your own risk.

## requirements
basically just bash and uhh python

## installation

```bash
git clone https://github.com/starsprinter92/linux-dos.git
cd dos-linux
cp dos ~/.local/bin/dos
chmod +x ~/.local/bin/dos
dos
```

make sure `~/.local/bin` is in your `$PATH`.
